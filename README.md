# Inertia (Python + Pygame)

A small puzzle game where the player (green ball) slides in 8 directions until hitting a wall or a start tile, collecting gems and avoiding bombs.

Run locally (Windows):

```bash
python -m pip install -r requirements.txt
python main.py
```

Controls:
- Left-click to slide towards the clicked direction (8-direction selection).
- Arrow keys or WASD to move.
- Diagonals: Q/E/Z/C or keypad 1/3/7/9
- R to restart, Esc or Q to quit.
